# Code of Conduct

## Our Standard

This project aims to be a respectful, practical, and technically rigorous space.

Examples of behavior that contributes to a positive environment include:

- giving constructive and specific feedback
- assuming good intent while still challenging weak technical arguments
- keeping discussions focused on the product, code, and user outcomes
- respecting different experience levels and backgrounds

Examples of unacceptable behavior include:

- personal attacks, insults, or harassment
- discriminatory or exclusionary language
- repeated bad-faith arguments or deliberate disruption
- publishing private information without consent

## Enforcement

Project maintainers may remove comments, close threads, or restrict participation for behavior that violates this code of conduct.

## Reporting

If you need to report a problem, open a private GitHub security advisory or contact the maintainer directly through GitHub.
