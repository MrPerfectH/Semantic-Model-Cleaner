# Security Policy

## Supported Versions

Security fixes are provided for the latest published `0.x` release line.

## Reporting a Vulnerability

Please do not report security issues in public issues.

Use one of these paths instead:

- open a private GitHub security advisory for this repository
- contact the maintainer privately through GitHub

When reporting, include:

- affected version or commit
- reproduction steps
- impact summary
- any suggested mitigation if known
