## Implemented behavior

Both layouts offer Open Power BI Project and Try demo. v2 starts with an unobscured welcome card. Selecting a folder reuses discovery, proposes a sole Semantic Model, or asks for an explicit choice when several exist. Startup roots with multiple models also require a choice.

A read-only `/api/scope` endpoint reuses the R04 Report binding function. Selected and excluded Reports and their reasons are shown before Analyze. Manual model/report roots and connected-report search remain available. The UI explains that other Reports may use the items and that analysis limitations are identified during analysis. No analysis or classification semantics changed.

Demo prepares a disposable copy and stops for scope review. Analyze remains an explicit action. PBIX-only/unsupported folders explain the supported Power BI Project/TMDL input and the Power BI Desktop conversion path. Invalid browse paths show inline guidance and disable folder confirmation until corrected; Cancel remains usable. Failed project/demo loads clear the pending scope, retain setup controls, and permit retry. Out-of-order project/demo and browse responses cannot overwrite newer selections.

The API demo contract is unchanged. Browser automation that previously assumed clicking demo also analyzes must now click Analyze after the scope review.
