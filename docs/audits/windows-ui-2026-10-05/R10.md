## Native Power BI investigation

Power BI Desktop Store version **2.158.1177.0** was exercised on disposable synthetic projects. Existing user report processes were preserved. The original analyzer fixture deliberately contains negative cases and initially also lacked Desktop-required metadata. Added valid `.platform`, PBIR version and page-order metadata to the common generator. Added a separate diagnostic Desktop derivative that removes invalid DAX, inferred-column and stale/missing-field cases and supplies database compatibility and V3 data-source metadata.

Microsoft's [report project format documentation](https://learn.microsoft.com/en-us/power-bi/developer/projects/projects-report) distinguishes definition.pbir version 4.0 from the PBIR definition version. The corrected definition uses 2.0.0, consistent with Microsoft's [authoring reference](https://github.com/microsoft/skills-for-fabric/blob/main/plugins/powerbi-authoring/skills/powerbi-report-cli/references/authoring/authoring-workflows.md). Model metadata follows the [TMDL reference](https://github.com/microsoft/skills-for-fabric/blob/main/plugins/powerbi-authoring/skills/semantic-model-authoring/references/tmdl-guidelines.md).

The corrected baseline opens with both report pages and Sales/Date model fields. Relationship and data refresh then produce visual query errors **before any cleaner mutation**. This prevents a meaningful before/after behavior comparison. Opening successfully alone is not runtime acceptance, and the diagnostic derivative is not advertised as a fully working Desktop sample.

[desktop-roundtrip.json](package/desktop-roundtrip.json) records a separate file-level check against the extracted ZIP: preview does not mutate metadata, a reviewed deletion of the unused synthetic measure applies and verifies, and recovery restores project metadata byte-for-byte. This does not repair or waive the baseline visual failure. Full native screenshots remain in ignored local scratch storage because window chrome contains account information; only synthetic error-dialog captures are included in package evidence.
