## Failures found and fixed during acceptance

- History sorted random plan IDs, showing unrelated older receipts first. It now sorts actual creation/update times and shows scope/time in v2; regression verified.
- A bracketed IPv6 trusted-host entry behaved differently across Werkzeug versions and could match an unintended host. Trusted hosts now match the IPv4-only loopback launchers; negative IPv6/token/origin regressions pass.
- Schema validation crashed when reports and the launch workspace were on different Windows drives. It now keeps distinct report-relative evidence paths when cross-drive relative paths are impossible; reproduced regression and Windows CI pass.
- Wheel acceptance had hardcoded beta3 identity. It now compares the declared release version with the independently installed package and served UI; fresh beta4 installation passes.
- The earlier synthetic native baseline was invalid before cleaner operations. The generator now emits typed M columns and correct TMDL source-column properties. Its separate Desktop derivative uses supported local-model measures and PBIR metadata. Analyzer stress fixtures retain deliberate negative cases. Native refresh/DAX now establish a valid comparison.

## Remaining boundaries and follow-up

This is a scoped public beta, not a stable release or runtime-equivalence guarantee for arbitrary models. Supported inputs are local TMDL Semantic Models and selected connected enhanced-PBIR Reports. PBIX is not direct input. Safe means supported scanned static metadata; unsupported/dynamic coverage remains Review. BOM-prefixed TMDL scopes are read-only for saved changes. Review exact differences and retain backups.

The executable is **unsigned**. Clean-runner functional acceptance passed; downloaded-file SmartScreen reputation behavior on consumer installations is **not established**. A local Defender custom scan was skipped, so no clean antivirus scan is claimed. No security controls were disabled. Retain these distribution limitations in public guidance.

There were **zero independent usability-study participants**. Agent visual, keyboard, zoom and recovery checks are complete under the user's delegation; they do not establish independent first-use success. A public-beta feedback round remains recommended. R13's optional machine-readable operation schema is deferred; the supported CLI already provides discovery, structured output and reviewed plans.

R05-F1 (CI), R09-F1 (scaling), R10-F1 (native runtime) and R12-F2 (new identity/exact artifact) are closed. R10-F2 has passed separate-runner functional acceptance with consumer reputation behavior explicitly unverified. R12-F1 remains a research follow-up, not a completed study. R01–R12 implementation and delegated engineering acceptance are complete.

No real user project was changed. Original checkout, unrelated worktrees and existing Power BI sessions were preserved. The PR is the reviewable delivery; merging, tagging, release uploads and announcements are separate publication actions.
