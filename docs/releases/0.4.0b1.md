# Semantic Model Cleaner 0.4.0b1 public beta

This is the first public beta of the free, MIT-licensed repository workflow for
local TMDL semantic models and PBIR reports.

## Choose an artifact

- Windows: `semantic-model-cleaner-windows-x64-0.4.0b1.zip` plus its
  `.sha256` sidecar. Extract the complete ZIP and run
  `Semantic Model Cleaner.exe`. The executable is unsigned.
- Python: the `.whl` or source `.tar.gz`, each with its own `.sha256`
  sidecar. Python 3.11 or newer is required.

The app analyzes only the local model and reports you select. Power BI Desktop,
Fabric, an account, and paid services are not required. Start with the
[quick start](https://github.com/MrPerfectH/Semantic-Model-Cleaner/blob/v0.4.0b1/docs/quickstart.md)
and review the
[support boundaries](https://github.com/MrPerfectH/Semantic-Model-Cleaner/blob/v0.4.0b1/docs/support.md)
before applying changes.

The release pipeline verifies version/tag/channel consistency, installs the
wheel and its dependencies in a fresh environment, and runs the downloaded
Windows ZIP in a separate Windows job. Publication occurs only after the EXE
passes browser-based demo and reversible-change verification.

## Correctness changes

- Connected-report discovery searches nested folders and reports binding exclusions.
- PBIR rewrites resolve reused aliases inside their owning queries and reject malformed required bindings.
- Expressionless TMDL measures retain their declaration boundaries during changes.
- DAX strings and comments no longer hide real dependencies. Cleanup protects retained field-parameter targets and table fragments.
- Invalid model folders, malformed root declarations and unreadable later TMDL files fail before analysis. UTF-8 BOM table headers analyze correctly.
- Retained sorting and hierarchy dependencies no longer show Safe cleanup recommendations; web counts match item states.
- Analyzer warnings display correctly and cleanup/report counts use consistent totals. Live and stale reference details retain hidden-page and hidden-visual flags.

Supported changes use exact previews, source-change checks, guarded application, verification and receipts with byte-exact restore. See the support matrix for operations that are deliberately blocked when their scope or reference coverage cannot be established.

The beta withholds legacy direct-write HTTP routes and `smc clean-stale --apply`. Use the saved-plan workflow for changes. The read-only `clean-stale` CLI now uses the same pass/findings/error exit convention as `check`: 0, 1 and 2.

Changes in model scopes containing UTF-8 BOM-prefixed TMDL are withheld, including older saved previews. Read-only analysis remains available; the beta does not claim complete BOM writer support.
