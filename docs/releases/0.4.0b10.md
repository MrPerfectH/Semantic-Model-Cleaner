# Semantic Model Cleaner 0.4.0b10 release candidate

This candidate integrates the cumulative engine fixes below. Public release remains pending; local installation evidence is recorded separately below.

## Changes

- **Format strings:** missing references in dynamic format-string expressions mark the owning item Broken without placing unrelated unused items at Review.
- **Whole-table dependencies:** preserve table-scoped dependency evidence and retain referenced tables and their columns while consumers remain.
- **Broken-item deletion:** Broken alone does not block deletion; dependency, coverage, and other applicable guards still apply.
- **Nullable report bindings:** normalize null binding alternatives and fail closed for invalid or ambiguous populated bindings without exposing binding values in warnings.
- **Review explanations:** show concrete item Review reasons in dependency explanations and the detail UI.
- **Structural units:** retain field parameters and calculation groups atomically. Whole-table removal requires Review confirmation, including generated columns, while retained consumers continue to protect the unit.
