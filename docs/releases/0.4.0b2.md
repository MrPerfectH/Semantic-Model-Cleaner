# Semantic Model Cleaner 0.4.0b2 public beta

This maintenance beta improves analysis of large metadata files and the first-run
folder picker. It includes the tabbed workspace, reviewed changes and recovery
workflows from 0.4.0b1.

## Changes

- Large culture/translation metadata scans match unquoted DAX table names directly
  in the original text. This removes repeated copies of the remaining metadata
  during scanning, while preserving the reference-matching rules.
- On first use, model and comparison folder pickers start at `/Users` when that
  directory exists. Platforms without `/Users` fall back to the working directory.
  Existing selections and saved browse locations take precedence. The same
  defaults apply to the classic and default tabbed layouts.
- Release publication selects the notes for the validated release version instead
  of reusing the previous beta's notes.

## Install

- Windows: download `semantic-model-cleaner-windows-x64-0.4.0b2.zip` and its
  `.sha256` sidecar, verify the checksum and extract the complete ZIP before
  running `Semantic Model Cleaner.exe`. The executable is unsigned.
- Python: install the `.whl` or source `.tar.gz`; Python 3.11 or newer is required.
  Both artifacts include SHA-256 sidecars.

See the [quick start](https://github.com/MrPerfectH/Semantic-Model-Cleaner/blob/v0.4.0b2/docs/quickstart.md)
and [support boundaries](https://github.com/MrPerfectH/Semantic-Model-Cleaner/blob/v0.4.0b2/docs/support.md).

## Validation and boundaries

The release workflow gates publication on source checks, a fresh wheel installation
and verification of the downloaded Windows ZIP in a separate browser-driven job.
Workflow results and verification artifacts provide the evidence for this release.
No timing guarantee is attached to the metadata-scan improvement.

The app continues to analyze local TMDL/PBIR projects and the selected reports.
Calculation-group and dynamic-reference coverage remains incomplete. Changes in
model scopes containing BOM-prefixed TMDL remain withheld; read-only analysis is
available. Review exact saved-plan differences before applying changes.
