# Semantic Model Cleaner 0.4.0b4 public beta

This Windows-focused beta improves first analysis, explains cleanup scope and makes reviewed changes easier to recover. It strengthens file protection and automation contracts.

## Changes

- Open a project or try a demo, review one Semantic Model and connected Reports, then analyze. Results distinguish Safe/Review candidates, coverage limits and Report Health.
- Inspect evidence and exact saved-plan differences before applying. History shows recent activity and scope; verify applied changes and review restoration differences before recovery.
- Keyboard-accessible dialogs retain focus, support Escape and keep cancellation reachable. Both layouts were checked at enlarged browser zoom and Windows scaling. Fonts are bundled for offline use.
- Exports reject source-file aliases. Windows Unicode handling, stale-plan protection and byte-exact recovery have regression coverage. Local HTTP APIs require a launch token and enforce loopback host/origin boundaries.
- CLI discovery and structured JSON errors support automation and AI coding agents. Cross-drive Windows projects can complete schema validation.

- Translation membership is informational evidence with culture and source locations; it does not by itself block cleanup. Linguistic metadata remains an explicit analysis limitation. Culture files are not yet rewritten by rename/delete operations.
- Unused calculation groups and field parameters require Review by entity type. Whole-entity plans show the reason once and ask for confirmation.

## Install and verify

Extract the complete `semantic-model-cleaner-windows-x64-0.4.0b4.zip`, verify its SHA-256 sidecar, and launch `Semantic Model Cleaner.exe`. Python is not required for the Windows app. The executable is unsigned; Windows may show a reputation warning.

Python users can install the wheel or source distribution with Python 3.11 or later. See the [quick start](https://github.com/MrPerfectH/Semantic-Model-Cleaner/blob/v0.4.0b4/docs/quickstart.md) and [support boundaries](https://github.com/MrPerfectH/Semantic-Model-Cleaner/blob/v0.4.0b4/docs/support.md).

The release workflow checks source tests, fresh wheel installation and the downloaded Windows ZIP on a separate runner before publishing. The [candidate verification record](https://github.com/MrPerfectH/Semantic-Model-Cleaner/blob/v0.4.0b4/docs/audits/windows-ui-2026-10-05/R12.md) records the earlier native Power BI, keyboard, scaling and recovery acceptance. Final release builds have their own manifests and checksums; use the sidecars attached to this release.

## Boundaries

Use local TMDL/PBIR projects and selected connected Reports; PBIX is not direct input. Safe reflects supported scanned metadata, not all possible external consumers or dynamic expressions. Review limitations and saved differences. BOM-prefixed TMDL scopes remain read-only for saved changes. This beta does not guarantee runtime equivalence for arbitrary models. Independent first-use research and consumer SmartScreen reputation testing have not been completed.
