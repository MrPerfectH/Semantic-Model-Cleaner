# Semantic Model Cleaner 0.4.0b5 public beta

This beta improves semantic-model impact analysis and cleanup previews for multi-model repositories.

## Changes

- `items` and `usage` share the same single-item deletion recommendation. Known consumers block deleting an item alone, including when its DAX is broken.
- A published catalog with a different model name is excluded as `not_connected`; missing, malformed and conflicting catalogs remain unverified. Both `Initial Catalog` and `initialcatalog` are supported. Matching uses folder/display names, not verified service identity.
- Calculation-item selected-value and format context no longer puts unrelated unused items at Review. Explicit item references remain protected, while name-based branching, unresolved references and bare-table expressions remain conservative.
- `smc cleanup-groups` previews dead measure components, including chains and cycles, and checks coordinated deletion with the existing deletion policy. It does not delete files.
- `items` adds machine-readable `status_code` and `via`, preserving the legacy display status. Query capabilities advertise contract `insights/1.1`; the response envelope stays at 1.0.
- Queries support `--unused` on items, `--all` for unbounded collections, and `-o`/`--output` for UTF-8 response files. Output cannot overwrite model/report artifacts.

## Install and verify

Install the attached Python wheel with Python 3.11 or later, or extract the complete Windows ZIP. Verify the SHA-256 sidecar. Run `smc --version` and `smc capabilities` to confirm version 0.4.0b5 and query contract insights/1.1.

The release workflow checks source tests, fresh wheel installation, and the downloaded Windows ZIP before publishing.

## Boundaries

Safe applies to supported selected local files. External consumers and runtime DAX equivalence are not verified. Dead-group previews cover measures; metadata references and outside consumers can require Review. Use the existing saved-plan review, apply and verify workflow before deleting anything. This release does not claim a new native Power BI report-rendering acceptance test.
