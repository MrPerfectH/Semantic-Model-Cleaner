# Semantic Model Cleaner 0.4.0b6 public beta

This beta closes the remaining named-calendar coverage gap in metadata expressions.

## Changes

- Genuine TMDL calendar declarations resolve named calendar references to their declaring table. All columns of that table remain conservatively protected; calendar categories are not guessed.
- Known, unique calendars produce targeted dependencies instead of downgrading every unrelated unused item. Unknown calendars, duplicate declarations, calendar/table name collisions and ordinary unsupported bare-table metadata consumers still keep shared coverage incomplete.
- Deletion validation blocks partial removal of columns in a retained named calendar, even when there is no report reference to them.
- The CLI improvements from beta5 remain: consistent verdicts, precise report bindings, dead measure groups, structured status fields, filters, response files and unbounded output.

## Verification and boundaries

Tests cover quoted and unquoted calendar names, owner-column protection, unresolved and ambiguous references, and false declarations in comments/expressions. Full Linux/Windows CI, fresh-wheel installation and downloaded Windows ZIP checks run before publication.

Real local model verification confirms complete supported scan coverage, while retained field parameters and metadata dependencies still require Review. Safe remains limited to selected local files; it does not establish external-consumer coverage or Power BI runtime equivalence. This release does not delete model or report items.
