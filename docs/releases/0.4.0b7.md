# Semantic Model Cleaner 0.4.0b7 public beta

This beta fixes release and documentation problems found when the published 0.4.0b6 assets were tested as a user would receive them. Analysis and cleanup behavior are unchanged from 0.4.0b6.

## Changes

- The landing page, quick start and support guide linked the 0.4.0b4 download. They now point at the current release, and a test keeps every public-facing document on the packaged version.
- The Windows ZIP `.sha256` file now ends with a newline that `sha256sum -c` accepts on Linux and macOS, as well as `Get-FileHash` comparison on Windows. The hash itself was always correct.
- The web app has a browser icon, so the browser no longer logs a failed icon request on every page load.
- The README now reminds you to back up or commit your Power BI Project before applying changes.
- The README explains that the CLI `unused` list and the JSON `summary.not_used` total include Stale only items, so they can exceed the web app's "Not used" count by exactly those items.

## Verification and boundaries

Full Linux and Windows CI, a fresh-wheel installation and a downloaded Windows ZIP check run before publication. The 0.4.0b6 wheel and ZIP were also exercised end to end: CLI plan, diff, apply, verify and restore recovered the original model byte for byte, and the packaged EXE passed the Windows browser smoke test.

The Windows download is unsigned, so Windows may show an unknown-publisher warning; compare the ZIP's SHA-256 with the `.sha256` file from the same release. Safe remains limited to the selected local files; it does not establish external-consumer coverage or Power BI runtime equivalence. This release does not delete model or report items.
