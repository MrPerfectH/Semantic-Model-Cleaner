# Semantic Model Cleaner 0.4.0b8 public beta

This beta is the usability round from the 2026-10-13 feedback review. It changes how results are shown and how stale report references are cleaned. Core analysis rules are unchanged except where noted below.

## Changes

- **Item and table pages:** fewer tabs, no DAX on Overview, and no repeated right sidebar.
- **References tab:** one table row per visual, with readable visual names and types.
- **Dependencies:** a lineage graph and related-table cards. You can move through calculation lineage from the page.
- **Analysis Limitations:** they have their own view with compact, labelled rows. They no longer crowd the first view or the object pages.
- **Calculation item expressions and named calendars** now resolve as model dependencies. They no longer end up in Analysis Limitations.
- **Report health:** stale references clean up in one click, with Undo and no second preview.
- **Scrolling:** the page scrolls again when "How to read these results" is open.
- **Connected Reports:** the Analysis scope shows only connected Reports.
- **Removed:** Semantic Model Compare.
- **VS Code Cleaner:** it finds repository models and their connected Reports on its own.
- **Header:** wheel and ZIP installs show only the version. They no longer show "commit unknown".

## Verification and boundaries

Full Linux and Windows CI, a fresh-wheel installation and a downloaded Windows ZIP check run before publication. The packaged UI smoke test covers the References table and calculation lineage.

The Windows download is unsigned, so Windows may show an unknown-publisher warning; compare the ZIP's SHA-256 with the `.sha256` file from the same release. Safe remains limited to the selected local files; it does not establish external-consumer coverage or Power BI runtime equivalence. This release does not delete model or report items.
