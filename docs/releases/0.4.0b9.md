# Semantic Model Cleaner 0.4.0b9 public beta

This beta improves how downstream measures and scan information are presented. Cleanup Recommendations and deletion guards remain unchanged.

## Changes

- **Downstream measures:** the Direct and Indirect lists show the complete downstream measure sets, with search, pagination, and navigation to each measure.
- **Scan details:** secondary scan information appears in a compact informational section, separate from Cleanup Recommendations.
- **Scan details effect wording (pending integration):** the release preparation includes a separate correction for cases where affected items have Review and Blocked recommendations. The correction must be integrated and verified before publication; it changes explanatory copy without weakening cleanup decisions.

## Verification and boundaries

Release metadata is prepared for 0.4.0b9. The final combined source still requires Linux and Windows CI, a fresh-wheel installation, and verification of the downloaded Windows ZIP before publication. This preparation does not establish packaged Windows behavior or human acceptance of the final release.

Compare the Windows ZIP's SHA-256 with the `.sha256` file from the same release. Signing follows the existing release configuration; no signing settings change in this preparation.
