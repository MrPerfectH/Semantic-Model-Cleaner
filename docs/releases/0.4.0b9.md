# Semantic Model Cleaner 0.4.0b9 public beta

This beta improves downstream dependency lists, Scan details, and the inventory and object-detail layout. Cleanup Recommendations and deletion guards remain unchanged.

## Changes

- **Downstream measures:** complete supported Direct and Indirect dependency lists, with home tables, search, pagination, and navigation to each measure.
- **Scan details:** known zero-impact entries use a neutral, collapsed informational presentation. Shared and unknown coverage retain warning presentation and inspectable evidence.
- **Effect wording:** limitation rows report incomplete coverage without implying a cleanup status. Expanded explanations preserve existing Blocked and Keep recommendations and explain when unused items need Review, without changing item classifications or counts.
- **Layout:** updated cobalt styling for inventories and object detail pages.

## Verification and boundaries

Package verification covers version identity, distribution installation, Windows ZIP consumption, and automated tests. Agent-operated desktop checks are separate from personal visual approval and do not establish Power BI runtime equivalence.

Compare the Windows ZIP's SHA-256 with the `.sha256` file from this same release. The Windows ZIP is unsigned, so Windows may show an unknown-publisher warning. Safe remains limited to the selected local files; it does not establish external-consumer coverage. Fabric connections remain unavailable; analysis uses local Power BI Project files.
