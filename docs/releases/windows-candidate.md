# Windows beta4

The Windows beta4 work is now available in the [0.4.0b4 public release](https://github.com/MrPerfectH/Semantic-Model-Cleaner/releases/tag/v0.4.0b4). See the [release notes](0.4.0b4.md), [quick start](../quickstart.md) and [support boundaries](../support.md).

The implementation from PR #104 is combined with the translation-evidence and entity-type review fixes merged afterward. Release CI rebuilds and verifies the packages from the tagged source. Use the checksums attached to the public release; the earlier local candidate hash in the [historical verification record](../audits/windows-ui-2026-10-05/R12.md) identifies a different build and must not be used to verify the public ZIP.

The beta remains unsigned and limited to supported static metadata in the selected model/report scope. Consumer SmartScreen reputation behavior and independent first-use research are not established. Original beta3 assets remain unchanged.
