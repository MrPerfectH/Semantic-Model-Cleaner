# Public Demo Workspace

This directory contains a synthetic PBIR + TMDL workspace that is safe to share publicly.

Use it to:

- validate local setup
- generate screenshots or demo recordings
- test the CLI or local web app without private model files

Suggested commands:

```bash
semantic-model-cleaner examples/public-demo-workspace --format full
semantic-model-cleaner-web examples/public-demo-workspace
```
