Semantic Model Cleaner 0.4.0b1 (public beta)
================================================

1. Extract the complete ZIP to a local folder.
2. Run "Semantic Model Cleaner.exe".
3. The app opens a local browser page. Your TMDL and PBIR files stay on your
   computer; no Power BI Desktop or Fabric connection is required.

This beta is unsigned, so Windows may show a reputation warning. Verify the
ZIP against its SHA-256 file on the GitHub prerelease page before extracting.

Support and known limits:
https://github.com/MrPerfectH/Semantic-Model-Cleaner/blob/v0.4.0b1/docs/support.md
