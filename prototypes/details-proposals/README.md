# Details Page Proposals

Three local-only design directions for the `Details` page.

These are static prototypes. They do not change the production UI and they are not wired to backend data yet.

Files:

- `index.html`: proposal launcher with short comparison
- `proposal-01-evidence-first.html`: report evidence first, model-only usage split out clearly
- `proposal-02-split-workspace.html`: more analytical workspace with grouped sections
- `proposal-03-review-queue.html`: cleanup-first flow with queues and bulk actions

Suggested reading order:

1. `proposal-01-evidence-first.html`
2. `proposal-03-review-queue.html`
3. `proposal-02-split-workspace.html`

Recommendation right now:

- Best public/stable candidate: `proposal-01-evidence-first.html`
- Best cleanup-heavy candidate: `proposal-03-review-queue.html`
- Best exploratory/beta candidate: `proposal-02-split-workspace.html`
